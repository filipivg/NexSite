# NexSite

Plataforma de divulgação e descoberta de sites e empresas.

> *"Enquanto o Google ajuda você a achar o que já procura, o NexSite ajuda você a descobrir o que ainda não conhecia."*

## Sobre

O NexSite conecta pessoas a negócios que elas ainda não conhecem e dá visibilidade a empresas que querem alcançar novos clientes. Este repositório contém o **protótipo front-end** da plataforma, com as principais telas e interações simuladas.

## Funcionalidades

- **Busca de empresas** por nome, categoria e serviço
- **Filtros** por categoria, localização e faixa de preço (versão desktop e mobile)
- **Resultados** com ordenação, paginação, favoritos e destaque para empresas patrocinadas
- **Cadastro em duas etapas** para dois perfis: quem busca empresas e quem quer divulgar a sua
- **Login** com validação simulada

## Telas

| Arquivo | Descrição |
|---|---|
| `index.html` | Página inicial: busca, categorias, empresas em destaque e "Como funciona" |
| `busca.html` | Resultados com filtros laterais, ordenação e paginação |
| `filtros.html` | Tela de filtros otimizada para mobile |
| `login.html` | Entrar na conta |
| `cadastro.html` | Criação de conta em duas etapas |
| `script.js` | Interações: busca, favoritos, paginação, limpar filtros e formulários |

## Tecnologias

HTML5 · CSS3 · JavaScript (vanilla) · Google Fonts (Fraunces e Inter)

## Como executar

Não há dependências. Clone o repositório e abra o `index.html` no navegador:

```bash
git clone https://github.com/filipivg/NexSite.git
cd NexSite
# abra o index.html no navegador
```
